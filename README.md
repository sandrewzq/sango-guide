## 原始数据

全部由游戏本体的数据包（`GameData.PCK` / `Patch.pck`）解包后直接导出，**非人工抄录**，因此包含隐藏条目与未启用条目（表中以「是否启用」等字段标注）。

| 文件 | 规模 | 说明 |
|---|---:|---|
| `武将列表.csv` | 901 行 × 30 列 | 姓名、五维、忠诚、种族、亲族、熟练度… |
| `城市列表.csv` | 1917 行 × 10 列 | 按剧本分列，人口／民心／经济／城防… |
| `物品列表.csv` | 417 行 × 37 列 | 武器坐骑道具，各剧本出现率 |
| `官职列表.csv` | 188 行 × 33 列 | 消耗功勋、带将数、加成、限定武将 |
| `军师技列表.csv` | 107 行 × 21 列 | 效果、消耗技力、范围、智力武力上下限 |
| `兵种列表.csv` | 58 行 × 12 列 | 生命／速度／攻距／升级链 |
| `兵种克制表.csv` | 58 行 × 60 列 | 完整克制矩阵 |

均为 **UTF-8（带 BOM）**，Excel、Vim、pandas 都能直接读，不会乱码。
