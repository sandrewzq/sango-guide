内 政 机 制 指 南

三国群英传 V　·　一季能干几件事、人怎么挖、宝从哪来

先弄清四件事

  • 内政按季做（春 / 夏 / 秋 / 冬），每座城每季下一个命令，不是随时点。
  • 册封、说服、招降每季都有名额上限。游戏原文：「本季尚可册封的武将共 N 位」 「本季已无人才可进行说服」「本季已无俘虏可进行招降」。
  • 挖人成功与否，头号因素是忠诚（每个武将天生带一个固定值，武将资料面板里能看），其次才是手段和钱。
  • 先说清楚：成功率、产出概率这类数字，游戏文件里没有—— 它们是编译在程序里的。下面每条都注明了出处在哪，没依据的不编。

一、一季的八条内政命令

进城的「内政」选单里就是这八条。

命令管什么
任命太守换这座城的太守，太守能力影响该城内政效率
商业开发提升城市开发度，开发越高收入越多
搜索探查在城里搜寻人才与宝物，可能碰上事件（见第五节）
防御筑城提升城防，守城时的本钱
整顿治安维持治安，治安差会闹民变、掉人口
征预备兵把人口转成预备兵，打仗补员全靠它
训练士气练部队士气，士气高打得狠
地牢俘虏处理关在城里的敌将，招降 / 斩首都在这

城里另有：税率（调高了钱多但民心掉）、 全城最大征兵、全城兵力撤除。

二、每座城身上记着这些数

数据含义
人口征兵和收税的根本，被打会掉
金钱城的库存，发俸禄、送礼、征兵都花钱
民心内政好坏的结果，低了容易出乱子
开发商业开发累积，越高税收越多
防御筑城累积，攻城时对方要啃的本钱
预备兵随时能补进部队的兵源
内政做完会给一句评语，就是效果提示： 好的是「小有成效 / 成效良好 / 政绩卓越 / 民安城富」， 差的是「昏庸无能，导致损失惨重 / 处置失当，导致大量损失 / 及时处置，导致少许损失」。 看到「昏庸无能」就说明该城太守能力太差，换人。

三、人怎么挖：两种场合，各有一套手段

说服人才（对在野武将）

  • 请求——礼貌相邀，成功靠声望
  • 重利——给钱，界面要填「给予金额」
  • 说服——让有魅力的武将去谈
  • 也有自动说服，一键全谈一遍

招降敌将（对地牢俘虏）

  • 劝降——陈说形势，讲道理
  • 威胁——以死相逼
  • 酷刑——用刑，消耗对方意志
  • 利诱——给钱免罪
  • 也有自动招降，另有自动斩首

每种手段在游戏里都有成套台词。哪种手段对哪种武将有效，文件里没有对应表， 但选错手段会被直接喷回来——原文里最高傲的一句是 「便是只得做一村夫野人，也断不出仕汝军，莫再痴心妄想」。

四、能不能挖到，先看这个人的「忠诚」

每个武将都有一个天生的忠诚，游戏里打开武将资料面板就能看到这一项。 它决定了这个人好不好招、会不会叛：

忠诚代表武将你要有心理准备
90 ~ 100 关羽 100、诸葛亮 100、周瑜 100、张飞 99、赵云 98、孙策 94 砸钱、威胁、上刑基本无效，这种人只认旧主
50 ~ 89 曹操 88、张辽 68、荀彧 65、郭嘉 63 正常招，看手段和诚意
40 ~ 49 于禁 42、孟达 43、黄忠 41 被俘后有戏，但也容易被别人挖
40 以下 吕布 27、董卓 30、魏延 36、许子将 32、管辂 25 一被俘基本就降；反过来，你自己手下这种人也要盯紧
实用结论：想补猛将，别盯着蜀汉那批死忠——他们是打不动的。 把机会留给吕布（武 100 / 忠诚 27）、黄忠（95 / 41）、魏延（94 / 36）、董卓（92 / 30） 这类「有本事又挖得动」的。军师里则是 贾诩（智 97 / 51）、钟会（96 / 55）、许子将（95 / 32）、司马徽（95 / 39）。

五、搜索探查能碰上什么

数据里明写着的探索事件有这些，选项和奖励都在游戏文本里：

碰上你能做什么可能拿到
水底沉船打捞 / 放弃宝物、物品、金钱
上古石碑解读（识别不了就白跑） 习得武将技——读完石碑立刻粉碎，机会只有一次
云游仙人挑战 / 通过考验 / 绕路 智力+ / 武力+ / 体力上限+ / 技力上限+，或全员兵力增加； 打不过就被仙人击败
山贼、暴民讨伐 / 收编 / 撤退兵力、金钱
异象留意神兽出没的提示（毒龙潭 / 猛虎穴 / 大雪山 / 火焰山 / 兽神洞 / 桃源乡）

另外城里还会自己冒好事和坏事——

  • 好事：城中百姓来献家传宝物、富商赞助军资粮饷、青年壮丁自愿入伍从军、 外地人民迁徙入城、砖石工匠自愿修筑城墙、地方士绅劳军、市集规模扩大。
  • 坏事：暴民四处劫掠、士兵鼓噪叛变、人口向外迁移、城墙崩塌、 蝗虫侵袭、无名火灾、山洪围城、市集萎缩。

六、三个容易被忽略的机制

  • 储君——内政选单里有「设立储君」。君主一旦阵亡、被俘或失踪， 储君立刻继位（游戏原文：「储君○○后继其位」）。没立储君的话政权会很被动， 而且储君上任不满一年不能换，开局就早点定下来。
  • 俘虏会越狱——关在地牢里的敌将不是稳的：「地牢人犯骚动，趁隙脱逃」 「自○○地牢逃脱，顺利返回○○」。抓到人要么尽快处理，要么多留人守城。
  • 赏赐换忠诚——武将面板里有「忠诚」和「疲劳」两项。 拿赏赐品送人涨忠诚：玉器 +15、绸缎 +10、布匹 +5，龙纹白玉 +50、四灵宝镜 +80。 连战会累积疲劳，注意轮换。

七、名将还能复活

数据表里有 44 名武将被特别标记为可复活，对应游戏里的「复活名将」机制—— 学会木人力士后可以把他们拉回来。游戏原文： 「复活名将：……等人习得木人力士！」「没有可以复活的武将！」

另外还有奥汀秘术与真奥汀秘术这类顶级秘术， 分雷霆 / 疾风 / 狂风 / 烈焰 / 烈火 / 怒涛 / 流水 / 大地八系，通过事件获取。

关于「刷宝」的实话：游戏文件里查不到物品掉落概率、搜索产出表、 招降成功率这类数值——它们编译在程序里，数据表只有 「有哪些东西」和「界面怎么显示」。所以能确定的只有： 高级货（书籍、神器）是装备而不是消耗品、一人只有一个道具栏； 拿宝的正路是占城后的探索事件 + 商店 + 战场缴获， 而事件触发取决于你派出去的武将，多练级、多派人搜比攒钱实在。
