阵 法 指 南

三国群英传 V　·　8 个阵形，一张表看完

四句话讲完阵法

  1. 开打前给整支部队选一个阵，全队共用，不用给每个武将单独设。
  2. 阵形只做一件事：给士兵加攻击 / 防御 / 速度，不改变兵种克制。
  3. 没有阵形相克。数据里 8 个阵形只有攻、防、速三个修正值， 不存在"这个阵克那个阵"——挑加成最合你打法的就行。
  4. 武将天生只会 4 种（方形、箭矢、圆形、钩形）， 另外 4 种要用阵法书学，而最强的那几个恰好都要学。

二、各阵详解（游戏原文）

方形之阵攻 0　防 0　速 0

方形之阵属于最基本的阵形，前排部署近战部队，后排部署远程部队是最典型的兵力配置方式。方形之阵在使用上并没有特别的优缺点，稳扎稳打就是它最大的特色，在初期战力较弱时也很容易运用。

翔鹰之阵攻 2　防 1　速 0

翔鹰之阵能够同时提升我军士兵攻击力、防御力，是相当强力的高等冲锋阵形，适合猛将集团进行强袭，具有快速冲散敌军阵势的功效。值得注意的是，如果部队的整体战力不足将使效果大打折扣，但到了后期战力强大时，翔鹰之阵将是扫荡敌军的极佳选择。

天地之阵攻 1　防 1　速 2

天地之阵是同时提升我军士兵防御力、攻击力、移动速度的高等阵型，几乎适合任何战术。前方横队攻时可冲锋开路、守时可作后方部队的屏障，后方部队则可自由搭配远程或近战军种，随时提供支援或掩护的火力。

雁形之阵攻 0　防 1　速 2

雁形之阵是能够同时提升士兵防御力、移动速度的高等阵型。由于大部分的兵力都集中于左右两军，且左右两军具有包围夹击与上下延伸的机动性，在快速突入敌军阵营后，可以立即产生包围的效果。使用此阵要特别注意，避免敌军突破阵形中央的空隙，将我军分割为2。要发挥雁形之阵的包围，至少要能够组成四名武将以上的部队。

箭矢之阵攻 0　防 0　速 2

箭矢之阵是重视速度的阵形，适合搭配移动速度慢的近战兵种，用来突击不擅近战的远程部队时，更有意想不到的奇效。要留意的是，若我军各兵种速度差距太大，使用箭矢之阵容易造成各部队距离过远，无法相互支援，敌军便有各个击破的机会。

钩形之阵攻 2　防 0　速 0

钩形之阵是重视攻击的阵形，成犄角之势的冲锋状态，可以提高我军士兵的攻击力。建议殿后的小队采用耐久力较高的军种，以免遭到敌军冲散阵形。在初期，武将只能组成3人左右的部队时，就能发挥钩形之阵的效果，是它的一大优点。

锥形之阵攻 2　防 0　速 2

锥形之阵是能够同时提升我军士兵攻击力、移动速度的高等阵型，主要特色在于兵力集中于中央纵队，在突破敌军的前锋防线时效果惊人。适合对付前锋薄弱、后方却有强大远程火力的敌军。锥形之阵至少要有四名以上的武将才容易发挥出效果。

圆形之阵攻 0　防 1　速 0

圆形之阵是重视防御的阵形，各部队互相连接，可以使士兵的防御力上升。两翼的小队可以部署速度较快的兵种，以机动支援中央移动较不灵活的部队。由于兵力过于密集，在遭受集中型的武将技攻击时容易造成大量的伤亡，这点是使用圆形之阵时必须注意的。

八本兵书都是消耗品，用掉就学会对应阵形（全势力通用）。

怎么选：想要全能就天地之阵（攻防速全加，唯一一个三项都加的）； 想一波推平就锥形之阵（攻速拉满，突破前锋最狠）； 将少（3 人以下）时用钩形之阵——它是低级阵里唯一一个能立刻见效的强攻阵。
